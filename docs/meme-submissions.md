# 社区表情包投稿

## 适合谁

只想分享表情、不想使用 Git 的贡献者。打开[奶-hub 表情投稿区](https://github.com/lin-alg/NaiLoong/issues/1)，直接在评论中上传图片即可；不需要 Fork、填写标签或创建新 Issue。

## 上传与留言

在评论框中拖入图片并等待上传完成，然后发布评论。可以附上表情的说明。

```text
奶蛙狂笑（可选说明）
```

投稿人不需要选择标签。处理投稿的贡献者会根据角色的 `tags.json` 选择标签。暂时只有动图和静态图分类；若想提交极短视频，可先转换为 GIF。长视频本仓库不收录。

单张原图严格不超过 5 MB，建议压缩到 2 MB 以下以减少下载时间。支持常见静态图片和 GIF；网站展示时使用 Webp 预览图。

## 投稿后

贡献者或维护者会将选中的评论图片转存到自己的公开 Fork 的 `image` 分支，再通过 PR 将记录加入对应分类文件。合并后主仓库会自动把新记录的原图生成预览图；网站卡片加载预览图，点击下载按钮才获取原图。发现图片链接失效或说明有误时，可以在原评论下补充信息。
