# 社区表情包投稿

如果想贡献奶科生物的表情，你只需要注册一个 GitHub 账号，然后在[投稿区](https://github.com/lin-alg/NaiLoong/issues/1)评论区上传图片即可。请看以下详细说明：

## 上传表情

1. 准备静态图或 GIF，单张不超过 **5 MB**，建议压到 2 MB 以下。支持jpg，png，gif格式。
2. 打开[投稿区](https://github.com/lin-alg/NaiLoong/issues/1)，把图片拖进评论框，上传完成后适当补充表情的说明，然后评论即可。
3. 请发布与奶科生物有关的表情，如“奶蛙”，“奶蛋”等。无关表情会被忽视。
4. 一个评论上传表情的数量应控制在五个以内。如需上传更多请分多个评论上传。

## 投稿后

机器人会在你的评论顶部标记状态：

| 状态 | 含义 |
| :--- | :--- |
| ⚪ 未处理 | 等待贡献者整理。 |
| 🟡 处理中 | 已有人通过 PR 整理这条投稿，等待合并PR。 |
| 🟢 已入库 | PR已合并，网站即将更新。 |
| 🔴 图片过大 / 重复图片 | 按提示编辑原评论，压缩或移除对应图片。 |

入库后，机器人会把图片渲染链接改成普通的超链接，再折叠评论，方便以后查找原图和来源。不会删除已入库评论。

## 常见问题

### 我需要 Fork、创建新 Issue 或填写标签吗？

都不用。在评论区上传图片即可，你可以说明该表情对应的奶科生物种类。

### 评论里出现了 `MEME-CLAIM-...`，我需要做什么？

你不用处理。这是整理投稿的人提交 PR 时使用的认领口令。

### 可以一次上传多张图片吗？

可以，每张图片都要符合大小限制。同一条评论中的图片会被统一整理，建议把想一起投稿的图片放在一条评论里，数量不超过五个。

### 可以投稿视频吗？

极短的视频请先转成 GIF，仍须满足 5 MB 限制；较长的视频暂不收录。

### 投稿后能修改图片或说明吗？

评论显示“未处理”时，可以编辑原评论。已经显示“处理中”或“已入库”时，就不能更改评论内容了。

### 想自己整理投稿、顺便学 GitHub，接下来做什么？

阅读[GitHub 新手投稿教程](github-beginner-guide.md)。
